# cpp07 — Templates

Covers function templates and class templates.

## Exercises

| Exercise | Description |
|----------|-------------|
| ex00 | `whatever.hpp` — `swap`, `min`, `max` function templates |
| ex01 | `iter` — function template that applies a function to every element of an array |
| ex02 | `Array<T>` — class template for a fixed-size array with bounds-checked access |

## Build

```sh
cd exNN && make
```
