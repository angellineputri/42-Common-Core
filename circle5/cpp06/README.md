# cpp06 — C++ Casts

Covers the four C++ explicit cast operators.

## Exercises

| Exercise | Description |
|----------|-------------|
| ex00 | `ScalarConverter` — converts a string literal to `char`, `int`, `float`, `double` using `static_cast` |
| ex01 | `Serializer` — converts a pointer to `uintptr_t` and back using `reinterpret_cast` |
| ex02 | Type identification — finds the actual derived type of a random `Base*` using `dynamic_cast` |

## Build

```sh
cd exNN && make
```
