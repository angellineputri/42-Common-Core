# cpp02 — Operator Overloading & Orthodox Canonical Form

Covers ad-hoc polymorphism, operator overloading, and the Orthodox Canonical Class Form (default constructor, copy constructor, copy assignment operator, destructor).

## Exercises

| Exercise | Description |
|----------|-------------|
| ex00 | `Fixed` — fixed-point number class, Orthodox Canonical Form |
| ex01 | `Fixed` — int/float constructors, `toFloat`, `toInt`, `<<` overload |
| ex02 | `Fixed` — arithmetic and comparison operators, `min`/`max` static methods |
| ex03 | `BSP` — point-in-triangle test using fixed-point arithmetic |

## Build

```sh
cd exNN && make
```
