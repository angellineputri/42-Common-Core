# cpp01 — Memory, References, Pointers

Covers heap allocation, references vs pointers, pointer-to-member, and file streams.

## Exercises

| Exercise | Description |
|----------|-------------|
| ex00 | `BraiiiiiiinnnzzzZ` — zombie class, stack vs heap allocation |
| ex01 | `Moar brainz!` — zombie horde, array heap allocation |
| ex02 | `HI THIS IS BRAIN` — reference vs pointer to a string |
| ex03 | `Unnecessary violence` — weapon class, references vs pointers |
| ex04 | `Sed is for losers` — file I/O, string replacement |
| ex05 | `Harl 2.0` — pointer-to-member-function for log level dispatch |
| ex06 | `Harl filter` — switch on log levels using pointer-to-member-function |

## Build

```sh
cd exNN && make
```
