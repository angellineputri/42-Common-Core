# cpp04 — Polymorphism & Interfaces

Covers subtype polymorphism, pure virtual functions, abstract classes, and interface design.

## Exercises

| Exercise | Description |
|----------|-------------|
| ex00 | `Animal` / `Dog` / `Cat` — virtual `makeSound`, wrong deep-copy without it |
| ex01 | Deep copy — `Brain` class, correct copy constructor and assignment |
| ex02 | Abstract `Animal` — pure virtual `makeSound` prevents direct instantiation |
| ex03 | `AMateria` — interface-based material system with `Ice` and `Cure` |

## Build

cd exNN && make
