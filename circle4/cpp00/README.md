# cpp00 — C++ Basics

Introduction to C++ fundamentals.

## Exercises

| Exercise | Description |
|----------|-------------|
| ex00 | `Megaphone` — uppercases command-line arguments |
| ex01 | `PhoneBook` — in-memory contact book using classes, with search by index |
| ex02 | `Account` — recreation of a banking account log from a provided header |

## Build

Each exercise has its own Makefile:

```sh
cd ex00 && make && ./megaphone "hello world"
cd ex01 && make && ./contact
cd ex02 && make && ./account
```
