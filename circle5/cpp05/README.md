# cpp05 — Exceptions

Covers C++ exception handling with `try`, `catch`, and custom exception classes.

## Exercises

| Exercise | Description |
|----------|-------------|
| ex00 | `Bureaucrat` — class with grade 1–150; throws `GradeTooHighException` / `GradeTooLowException` |
| ex01 | `Form` — signable form with grade requirements; throws on invalid state |
| ex02 | `AForm` / `ShrubberyCreationForm` / `RobotomyRequestForm` / `PresidentialPardonForm` — concrete form types |
| ex03 | `Intern` — creates forms by name; throws `FormNotFoundException` |

## Build

```sh
cd exNN && make
```
