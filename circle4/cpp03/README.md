# cpp03 — Inheritance

Covers single and multiple inheritance, base class constructors, and the diamond problem.

## Exercises

| Exercise | Description |
|----------|-------------|
| ex00 | `ClapTrap` — base robot class with HP, energy, attack |
| ex01 | `ScavTrap` — inherits ClapTrap, adds `guardGate` |
| ex02 | `FragTrap` — inherits ClapTrap, adds `highFivesGuys` |
| ex03 | `DiamondTrap` — inherits both ScavTrap and FragTrap (diamond inheritance) |

## Build

```sh
cd exNN && make
```
