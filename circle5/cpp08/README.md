# cpp08 — STL Containers & Algorithms

Covers templated containers, iterators, and STL algorithms.

## Exercises

| Exercise | Description |
|----------|-------------|
| ex00 | `easyfind` — function template that finds the first occurrence of a value in a container |
| ex01 | `Span` — class that stores N integers and finds shortest/longest span |
| ex02 | `MutantStack<T>` — extends `std::stack` to expose iterators |

## Build

```sh
cd exNN && make
```
